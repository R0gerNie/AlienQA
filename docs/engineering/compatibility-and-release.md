## Release gate

工程门槛是原始证据先保存、停止/失败后可审阅、URL→扫描→回放→决定/备注→analysis HTML、旧记录兼容、安装包完整路径。对应测试和安装证据逐项保留。

效果门槛仍开放：固定版本小应用的真实模型记录及全部 attempt、独立人审、开发者认可的有效发现、正常/例外对照投诉、审阅负担与费用记录。费用未知不能填零。首轮先建立基线，之后冻结阈值；没有用一个工程通过数替代模型准确率。

`summarize_t09_validation.py` 默认将没有证据的层标为 `not_run`，跳过/空测试为 `blocked`，失败保留；`release_ready` 不会仅因本机机制与安装通过变为 true。远程 CI、其他平台、真实模型和用户试用均不隐式升级。

## 试用与已知限制

试用路径：输入已运行 URL和必要的私有 session→设置本机模型/动作预算→扫描→核对依据、实际观察及范围→回放→决定/备注→导出 HTML。由开发者记录困惑、有效发现、未决、主动审阅分钟及全部调用成本；试用记录尚待真实参与者提供。

当前一般用户模型固定为具有通用网页经验、第一次使用该产品的人；不代表所有用户，也不推导产品未公开业务规则。frame/shadow 的额外支持、复杂组件/路由、其他框架广覆盖、岗位画像、PDF 和多人功能后置。

局部扫描、零发现和未完成 run 均不能表示全站 QA 通过。源码调查是后置假设，回放重现不替代认知合理性判断。会话、回放和私有模型记录留在本机，单独分享自包含 HTML；删除 session 后仍需清理 run 中的回放副本。
