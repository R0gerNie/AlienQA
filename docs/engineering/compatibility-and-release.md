## Release gate

工程门槛是原始证据先保存、停止/失败后可审阅、URL→扫描→回放→决定/备注→analysis HTML、旧记录兼容、安装包完整路径。对应测试和安装证据逐项保留。

真实模型的工程门槛是冻结运行及全部 attempt/原始结果可核对、覆盖与未处理项明确、合法候选和已报告发现不静默丢失。独立人审、开发者认可、误报率、正常/例外是否零发现和审阅分钟均不作为验收或发布条件。费用未知不能填零，用户可选择提供反馈。

`summarize_t09_validation.py` 的 matrix schema v2 明示 required_levels：structure、browser_mechanism、installation、real_model。independent_review 与 user_trial 为可选层，不影响 release_ready 或命令失败码。未运行、失败、跳过/空测试仍如实记录；本机通过不自动宣称其他平台/当前模型版本已验证。旧 summary 保留其历史门槛与结果，不能覆盖为新规则的成功证据。

## 试用与已知限制

试用路径：输入已运行 URL和必要的私有 session→设置本机模型/动作预算→扫描→核对依据、实际观察及范围→回放→决定/备注→导出 HTML。由开发者记录困惑、有效发现、未决、主动审阅分钟及全部调用成本；试用记录尚待真实参与者提供。

当前模型固定为懂相关行业、具有网页经验、第一次使用该产品的外部用户；不代表所有用户，也不推导产品未公开业务规则。frame/shadow 的额外支持、复杂组件/路由、其他框架广覆盖、岗位画像、PDF 和多人功能后置。

局部扫描、零发现和未完成 run 均不能表示全站 QA 通过。源码调查是后置假设，回放重现仅记录条件与信号，不裁判认知合理性。会话、回放和私有模型记录留在本机，单独分享自包含 HTML；删除 session 后仍需清理 run 中的回放副本。
