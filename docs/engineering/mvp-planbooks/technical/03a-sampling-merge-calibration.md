# T03a：N03 采样并集与候选保留

版本：2026-10-02-n03-calibration-4。父节点：[T03 N03](03-context-expectation-judgment.md)。当前产品契约见[总计划](../README.md#当前产品契约2026-10-02-定位修订)。

用户已明确“两次采样的结论应该取并集”，独立人审不作为验收、误报不设控制门槛。旧副计划中的“未知关系留为未决”“明确冲突阻断双方”和“正常/例外不能乱报”全部撤销为执行要求。历史真实批次与旧标注原样保留，见[校准记录](../../n03-calibration-results.md)。

## 1. 产品目标

AlienQA 模拟懂相关行业、但第一次使用本产品的外部用户，帮助发现只有内部人才觉得理所当然的地方。
某个要求只要被提出一次就进入检查，不要求第二次附议。模型如何形成主观怀疑由其自身知识与事前可见体验决定；是否采信和用于选定报告，由用户选择。

“关系不明”仅说明程序的有限规则不知道两条要求是否等价或兼容，不表示要求不合理。多采样只增加想到不同疑点的机会，不用来证明正确性；一次亦可运行，默认两次保留，成本与实际新增候选分别记录。

## 2. 生成与合并契约

- 当前版本：`general-user-v4 / sampling-merge-v3 / judgment-v3`。
- 事前输入保持隔离；模型可使用既有交互与行业知识。interface/history 的事实引用继续核对来源，interaction_convention 记录模型自己的联想，不由程序审核合理性。
- 取全部合法采样的并集，只有确定等价的完整要求才去重；保留原代表、各成员原文、basis、sample_index/row_index 和 support_count。支持数只是出现次数。
- 条件、否定、对象、时限、特定 toast、互斥和未知句式都不能因降低误报而删掉、强制泛化或拦截。relation_unknown/conflict 放在 relationship_warnings，所有相关组 decision=accepted。
- 每个响应最多 5 条是现有调用协议；并集可达到 `5 × requested_samples`，不再受独立的 5 条合并上限阻断。调用预算和输入裁剪仍显式记录，不以预算保证全站无漏报。
- 单份调用/解析失败保留其原始记录，并继续处理其他已验证采样；sampling.complete=false。全部采样无效仍是工程失败。取消仍停止，不为追求召回继续发调用。
- 空采样及弃权原因原样保留，不当作反对其它候选的票；空全集不是 passed。

## 3. 判定与交付契约

- 每个交付组在动作前冻结 expectation_id/text/basis，judge 不能改变原预期，也不能混用 run/step/action。
- 某些要求存在落差而其他要求无法判断时，保留 mismatch 和全部对应 Evidence，另列 unverifiable_expectation_ids/error；扫描显示不完整。全部可验证且符合才能 passed。
- 无法采集、错误身份、坏 schema、调用失败等仍是工程故障；不能伪造观察或出处。它们不属于主观认知“误报控制”。
- 技术异常独立保存；认知失败、调查失败或用户尚未审阅均不抹掉已有证据。
- 在线步骤和离线 analysis 显示全部候选、分歧备注、失败、弃权和局部未知。旧 unresolved/partial 记录仍如实读取。
- 用户的五态 Decision 与备注不改变原发现；confirmed 是主动选择的采信报告，analysis 无需人审即可导出。

## 4. 工程包与联合验收

| 工程包 | 模块 | 当前要求与验证 |
|---|---|---|
| C01 原始语料 | fixtures/sampling-calibration | 保存原始解析行和历史版本标签；旧人工注释仅是意见，不作为准入答案 |
| C02 等价归并 | sampling/contracts | 仅有限整句等价或排版等价可去重；其它要求全部保留，关系备注不 veto |
| C03 并集与身份 | roles/engine | 1/2/3 次采样均保留合法并集，单次出现有 ID；6～10 个组可交付；失败采样不清空有效采样 |
| C04 局部未知 | models/engine/pipeline | mismatch 与未知 ID 并存，证据保存；错误 ID/重复/交叉状态拒收，不变成成功 |
| C05 报告与选择权 | cognitive_diagnostics/UI/review | 同一组成员、关系备注和未知项在线/离线可见；所有 Decision 均在 analysis 中保留 |
| C06 复测与计量 | calibration/acceptance/T09 | 离线 v1/v2.2/current 分开回放；冻结版本后真实小样本核对覆盖及调用；不要求独立人审或误报阈值 |

工程回归包括：已知互斥、未知追加、附加条件、跨依据等价、仅一次出现、空采样、失败采样、超过 5 个并集组、混合落差/未知、身份错配、在线和复制后离线报告。

## 5. 验收与下一轮

工程验收检查：合法候选是否都有代表及来源、是否都进入判定、模型报出的落差是否进入 Evidence 与 analysis、未处理项是否明示、调用与失败是否对账。
受控故障可用断言检查技术采集及遗漏路径；正常/例外是输入对照，不预设它们必须零发现。可选用户反馈不改变 release_ready，不要求审阅分钟或“有效发现”批准。

本版本已完成[三款开源应用有界真实基线](../../open-source-applications.md)：另开授权 200 次，使用 105 次；97 个来源候选与 81 条合并要求完整保留，六份报告保存。24 步含 8 步无法判断及 1 次动作失败，没有提出 mismatch；不能推导全应用零落差。旧 98/100 批独立保留，控制样例的当前版本复跑仍开放。
下一轮优先处理 Memos 弹层/作用域探索与无文案目标描述、语义输入分支和焦点观察。复测门槛已记入应用记录；不自动消耗剩余 95 次，也不重置原始失败或未知记录。
优先依据实际遗漏改进探索、采集和候选传递；复测门槛冻结工程覆盖与不丢失，不冻结误报率或接受率。有限预算不承诺绝对无漏报。
